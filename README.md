# treinamento-automacao-API

Projeto de estudos e prática de automação de testes de API utilizando Cypress e JavaScript.

A ideia é praticar requisições HTTP, realizar validações e entender melhor como funciona a automação de testes de API.

## Tecnologias utilizadas

- JavaScript

- Cypress

- API REST

- Postman

## API utilizada

Restful Booker

## Cenários automatizados

**- GET:** Consultar todas as reservas.

**- GET:** Consultar uma reserva por ID.

**- POST:** Criar uma reserva.

**- PUT:** Atualizar uma reserva.

**- DELETE:** Excluir uma reserva.

## Validações

Durante os testes, são realizadas validações de status HTTP e dos dados retornados pela API, de acordo com cada cenário.
